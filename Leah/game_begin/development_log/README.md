# Development log

This folder records **why** the game changed, not a dump of every edit.

## How to write an entry

1. One file per decision or milestone.
2. Name: `YYYY-MM-DD-NN-short-slug.md` (NN is the order that day).
3. Keep it short: context, change, rationale, what we refused to do.

Later commercial work (payments, accounts, store builds) should add a new entry here before the code lands.
